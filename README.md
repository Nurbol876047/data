# Database Security Attacks — презентация + игра

## Как открыть
Двойной клик по **index.html** — работает без интернета и без сервера (three.js лежит в `vendor/`).
Игра — **game.html** (или кнопка «ИГРА» в презентации, клавиша `G`).

## Перед защитой
Впишите имена в `js/data.js`, первые строки:
```js
window.SPEAKERS = ['Участник 1', 'Участник 2', 'Участник 3', 'Участник 4'];
window.GROUP = 'Группа: ________';
```

## Управление
| Клавиша | Действие |
|---|---|
| `→` / `Пробел` / `PgDn` (кликер) | следующий шаг 3D-цикла, потом следующий слайд |
| `←` / `PgUp` | назад |
| клик по 3D-сцене | следующий шаг атаки |
| `1`–`4` | сразу к теме докладчика |
| `N` | подсказка «что сказать» (видна и на проекторе, если экран дублируется) |
| `R` / `A` | цикл заново / авто-показ |
| `O` | все слайды · `F` полный экран · `H` справка |

## Структура (19 слайдов)
Титул → команда → зачем защищать БД (CIA) → цепочка атаки →
по каждой теме 3 слайда: **введение** (простыми словами + реальный случай) → **3D-цикл атаки** (5 шагов + шаг защиты) → **защита** →
Defense in Depth → игра → спасибо.

## Игра «Взломай базу»
2–4 команды или режим «вся группа», 26 вопросов, таймер 15/20/30 с, бонус за скорость.
Ответ: клик или `1`–`4` / `A`–`D`, дальше — `Пробел`. Клик по карточке команды — передать ход.
